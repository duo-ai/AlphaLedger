# Social progress drafts

One file per day, `YYYY-MM-DD.md`, produced by `/social-update` in Claude Code
or `$social-update` in Codex.

These are drafts for human review. Nothing here is posted automatically. Every
claim in a draft carries the artifact it rests on, so a reviewer can check it
before anything is published.

Constraints live in the skill itself. The two that matter most: no profit,
loss, or balance figures of any kind, and every mention of trading says paper.
